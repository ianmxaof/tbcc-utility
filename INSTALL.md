# Sideload checklist

1. Download the release zip from https://github.com/ianmxaof/tbcc-utility/releases/latest  
2. Unzip (do not run from Downloads long-term — Chrome locks the path).  
3. `chrome://extensions` → Developer mode → **Load unpacked**.  
4. Pick the folder that contains `manifest.json` and `"name": "TBCC Operator"`.  
5. On x.com, open the TBCC gallery FAB → **Get TBCC** should open this repo if you need the page again.

### Verify

- Context menu on X media includes **TBCC Operator** (when the extension is enabled).  
- Overlay top bar: **Close** on the left, **ZIP all** on the right.  
- Lightbox: **View: N-up** cycles 1 / 2 / 3 lanes; **+ / − / Reset** zoom; **Space + drag** pans.
